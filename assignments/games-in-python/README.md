
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a Hangman game in Python by practicing strings, loops, conditionals, user input, and random selection. The player will guess a hidden word before running out of attempts.

## 📝 Tasks

### 🛠️ Set Up the Game

#### Description
Choose a secret word from the provided word list and initialize the variables needed to track the round.

#### Requirements
Completed program should:

- Randomly select one word from the provided list.
- Track the letters guessed and the number of incorrect guesses.
- Set a maximum number of incorrect guesses for the round.
- Display the secret word as underscores, revealing letters that have been guessed correctly.

### 🛠️ Implement the Guessing Loop

#### Description
Let the player guess letters until they reveal the entire word or use all allowed incorrect guesses.

#### Requirements
Completed program should:

- Ask the player for a letter on each turn.
- Update and display the word progress after each guess.
- Keep track of and display the incorrect guesses remaining.
- End the game when the player guesses the word or runs out of attempts.
- Display a win or loss message and reveal the secret word if the player loses.
